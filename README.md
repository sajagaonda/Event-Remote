# Event Remote 사용 안내서

## 1. Event Remote는 무엇인가요?

**Event Remote**는 행사장에서 필요한 효과음과 배경음악을 빠르게 재생할 수 있는 프로그램입니다.

별도의 프로그램을 설치할 필요 없이, `event_remote_v2.html` 파일을 인터넷 브라우저에서 열면 바로 사용할 수 있습니다.

예를 들어 이런 상황에서 사용할 수 있습니다.

- 시상식에서 박수 소리 재생
- 수상자 발표 전에 두구두구 소리 재생
- 정답 / 오답 효과음 재생
- 행사 시작 전 배경음악 재생
- 쉬는 시간에 BGM 재생
- 행사 진행 중 필요한 내용을 메모

---

# 2. 실행 방법

사용 방법은 매우 간단합니다.

1. `event_remote_v2.html` 파일을 찾습니다.
2. 파일을 더블 클릭합니다.
3. Chrome, Edge 같은 인터넷 브라우저에서 화면이 열립니다.
4. 사용할 효과음과 음악 파일을 연결합니다.
5. 버튼을 눌러 소리를 재생합니다.

인터넷에 연결되어 있지 않아도 사용할 수 있습니다.

> 행사 전에 사용할 컴퓨터에서 미리 한 번 실행해 보는 것을 추천합니다.
> 

---

# 3. 효과음 패드

화면에서 가장 큰 버튼들이 **효과음 패드**입니다.

기본적으로 다음 버튼이 준비되어 있습니다.

- 👏 박수
- 👏👏 큰 박수
- 🎉 환호
- 🥁 두구두구
- ✨ 짜잔
- ✅ 정답
- ❌ 땡
- 🔔 띵동
- 💥 임팩트

버튼을 클릭하면 연결된 효과음이 바로 재생됩니다.

---

# 4. 효과음 파일 연결하기

처음 실행하면 효과음 파일은 연결되어 있지 않습니다.

각 효과음 버튼 아래에 있는 **파일 연결** 버튼을 누르면 됩니다.

예를 들어 박수 버튼에 박수 소리를 넣으려면:

1. `박수` 버튼 아래의 **파일 연결**을 누릅니다.
2. 컴퓨터에 있는 박수 MP3 또는 WAV 파일을 선택합니다.
3. 연결이 완료되면 파일 이름이 버튼에 표시됩니다.
4. 이제 큰 `박수` 버튼을 누르면 소리가 재생됩니다.

MP3, WAV 등 일반적인 오디오 파일을 사용할 수 있습니다.

---

# 5. 연결한 파일은 저장되나요?

네.

연결한 음원과 여러 설정은 사용한 브라우저에 저장됩니다.

그래서 같은 컴퓨터와 같은 브라우저에서 다시 열면 대부분 그대로 유지됩니다.

저장되는 내용은 다음과 같습니다.

- 연결한 효과음
- 연결한 BGM
- 효과음 버튼 이름
- 효과음 아이콘
- 볼륨
- Fade 시간
- DUCK 설정
- 연타 방지 설정
- 운영 메모

단, 브라우저의 인터넷 사용 기록이나 사이트 데이터를 삭제하면 저장된 내용도 사라질 수 있습니다.

행사 전에 반드시 한 번 다시 실행해서 음원이 정상적으로 남아 있는지 확인하세요.

# 6. 효과음 버튼 편집

각 효과음 버튼 아래에는 **편집** 버튼이 있습니다.

편집 버튼을 누르면 다음 내용을 바꿀 수 있습니다.

### 버튼 이름

예를 들어

`박수`

를

`수상자 박수`

처럼 바꿀 수 있습니다.

### 아이콘

👏 대신 원하는 이모지를 사용할 수 있습니다.

예:

- 🏆 수상
- 🎊 축하
- 🚨 경고
- 🎤 발표

### 재생 방식

효과음마다 재생 방법을 따로 정할 수 있습니다.

#### 중복 재생 허용

버튼을 여러 번 누르면 같은 소리가 겹쳐서 재생됩니다.

짧은 효과음을 빠르게 여러 번 사용하고 싶을 때 사용할 수 있습니다.

#### 다시 누르면 처음부터 재생

효과음이 재생 중이어도 버튼을 다시 누르면 처음부터 다시 시작합니다.

`짜잔`, `정답`, `땡`처럼 짧은 효과음에 사용하기 좋습니다.

#### 재생 중에는 다시 누르지 않음

한 번 재생된 효과음이 끝날 때까지 같은 버튼을 다시 눌러도 추가로 재생되지 않습니다.

`박수`, `환호`처럼 긴 효과음에 추천합니다.

#### 다시 누르면 즉시 정지

한 번 누르면 재생되고, 다시 누르면 바로 정지됩니다.

---

# 7. 효과음 Fade

박수나 환호가 너무 오래 재생되고 있을 때 소리를 갑자기 끊으면 어색할 수 있습니다.

이럴 때 **효과음 Fade**를 사용합니다.

화면의

**↘ 효과음 Fade**

버튼을 누르면 현재 재생 중인 효과음의 볼륨이 천천히 작아지면서 종료됩니다.

단축키는:

**Shift + F**

입니다.

Fade가 끝나는 시간은 설정에서 변경할 수 있습니다.

예:

- 1초
- 1.5초
- 3초

---

# 8. 효과음 즉시 정지

효과음을 바로 꺼야 할 때는

**■ 효과음 즉시 정지**

버튼을 사용합니다.

Fade와 다르게 소리가 바로 멈춥니다.

---

# 9. BGM 사용하기

BGM은 행사 중 계속 틀어놓는 배경음악입니다.

기본적으로 다음 슬롯이 준비되어 있습니다.

- 오프닝
- 휴식
- 시상식
- 엔딩

각 BGM에도 원하는 음악 파일을 연결할 수 있습니다.

예를 들어:

`시상식 → 파일 연결 → awards.mp3`

처럼 연결하면 됩니다.

---

# 10. BGM 재생과 정지

BGM을 선택하면 아래쪽에 재생 조작 버튼이 나타납니다.

### ▶ 재생

선택한 음악을 재생합니다.

### ⏸ 일시정지

음악을 잠시 멈춥니다.

다시 재생하면 멈췄던 위치부터 이어서 재생됩니다.

### ■ 정지

음악을 완전히 멈추고 처음 위치로 돌아갑니다.

---

# 11. BGM Fade

행사가 끝날 때 음악을 갑자기 끄는 것보다 천천히 줄이는 것이 자연스럽습니다.

이럴 때

**↘ BGM 페이드**

버튼을 누릅니다.

음악의 볼륨이 천천히 줄어든 뒤 정지됩니다.

단축키는:

**F**

입니다.

Fade 시간은 설정에서 변경할 수 있습니다.

---

# 12. 전체 Fade

효과음과 BGM을 동시에 자연스럽게 줄이고 싶을 때 사용합니다.

화면 아래의

**↘ 전체 Fade**

버튼을 누르면 됩니다.

현재 나오고 있는 모든 음악과 효과음이 천천히 작아진 뒤 정지합니다.

단축키:

**Shift + ESC**

정상적으로 행사 음악을 마무리할 때 사용하기 좋습니다.

---

# 13. 전체 정지

문제가 생겼을 때 가장 중요한 버튼입니다.

화면 아래에 있는

**⏹ 전체 정지**

버튼을 누르면 현재 재생되는 모든 효과음과 BGM이 즉시 정지합니다.

키보드에서는:

**ESC**

키를 누르면 됩니다.

예를 들어 잘못된 효과음을 틀었거나 갑자기 음향을 모두 꺼야 할 때 사용할 수 있습니다.

> `ESC`는 비상 정지 버튼이라고 생각하면 쉽습니다.
> 

---

# 14. DUCK 기능

DUCK은 효과음이 나올 때 BGM을 자동으로 작게 만들어 주는 기능입니다.

예를 들어 시상식 음악이 나오고 있는 상황에서 박수 버튼을 누르면:

1. BGM이 작아집니다.
2. 박수 소리가 잘 들립니다.
3. 박수 소리가 끝납니다.
4. BGM이 다시 원래 볼륨으로 돌아옵니다.

그래서 BGM과 효과음이 서로 너무 크게 겹치는 것을 줄일 수 있습니다.

설정에서 DUCK 기능을 켜거나 끌 수 있습니다.

또 BGM이 얼마나 작아질지도 설정할 수 있습니다.

예를 들어:

`DUCK 35%`

로 설정하면 효과음이 나오는 동안 BGM이 원래 볼륨의 약 35%까지 작아집니다.

---

# 15. 연타 방지

행사 중에는 버튼을 실수로 여러 번 누를 수도 있습니다.

예를 들어 박수 버튼을 빠르게 3번 누르면 박수 소리가 여러 개 겹쳐서 너무 크게 들릴 수 있습니다.

이를 막기 위해 **연타 방지 기능**이 있습니다.

설정에서 연타 방지 시간을 조절할 수 있습니다.

기본값은 약 0.55초입니다.

즉, 같은 버튼을 너무 빠르게 다시 누르면 두 번째 입력을 무시합니다.

---

# 16. 볼륨 조절

효과음과 BGM의 볼륨을 따로 조절할 수 있습니다.

### 효과음 볼륨

박수, 환호, 두구두구 등의 소리 크기를 조절합니다.

### BGM 볼륨

오프닝, 쉬는 시간, 시상식 음악 등의 소리 크기를 조절합니다.

예를 들어:

- 효과음: 80%
- BGM: 40%

처럼 사용할 수 있습니다.

행사장에서는 보통 BGM은 조금 작게, 효과음은 조금 크게 맞추면 편합니다.

---

# 17. 운영 메모

화면 오른쪽에는 **운영 메모**가 있습니다.

행사 중 기억해야 할 내용을 자유롭게 작성할 수 있습니다.

예:

`팀장님 멘트 끝나면 시상식 BGM`

`수상자 이름 발표 후 두구두구`

`단체사진 전에 엔딩 음악 준비`

작성한 메모는 자동으로 저장됩니다.

따로 저장 버튼을 누르지 않아도 됩니다.

---

# 18. 음향 체크

**음향 체크** 기능을 사용하면 간단한 테스트 소리를 재생할 수 있습니다.

버튼은 다음과 같습니다.

- L 왼쪽
- C 중앙
- R 오른쪽

약 0.8초 동안 테스트 소리가 나옵니다.

이를 이용해서 행사 전에 다음 내용을 확인할 수 있습니다.

- 스피커에서 소리가 나는지
- 왼쪽 스피커가 정상인지
- 오른쪽 스피커가 정상인지
- 컴퓨터와 음향 장비가 제대로 연결되어 있는지

단, 사용하는 컴퓨터나 음향 장비에 따라 좌우 분리가 정확하게 작동하지 않을 수도 있습니다.

---

# 19. 키보드 단축키

행사 중에는 마우스보다 키보드가 더 빠를 수 있습니다.

다음 단축키를 사용할 수 있습니다.

| 키 | 기능 |
| --- | --- |
| 1 ~ 9 | 효과음 재생 |
| Q | 오프닝 BGM |
| W | 휴식 BGM |
| E | 시상식 BGM |
| R | 엔딩 BGM |
| Space | BGM 재생 / 일시정지 |
| F | BGM Fade |
| Shift + F | 효과음 Fade |
| Shift + ESC | 전체 Fade |
| ESC | 모든 소리 즉시 정지 |

행사 전에 자주 사용하는 단축키만 기억해도 충분합니다.

특히 다음 세 개는 알아두면 좋습니다.

**1~9 = 효과음**

**F = BGM Fade**

**ESC = 전체 정지**

---

# 20. 설정 메뉴

화면 위쪽의 ⚙️ 버튼을 누르면 설정 메뉴가 열립니다.

다음 내용을 변경할 수 있습니다.

- 효과음 연타 방지 시간
- 효과음 Fade 시간
- BGM Fade 시간
- 전체 Fade 시간
- DUCK 사용 여부
- DUCK 볼륨
- 음향 체크 화면 표시 여부

설정한 값은 자동으로 저장됩니다.

---

# 21. 초기화

설정 화면에는 **설정/음원 초기화** 버튼이 있습니다.

이 버튼을 누르면 저장되어 있던 내용이 삭제됩니다.

삭제되는 내용:

- 연결한 음원
- 효과음 버튼 이름
- 효과음 아이콘
- 효과음 재생 방식
- 운영 메모
- 볼륨 설정
- Fade 설정
- DUCK 설정

실수로 누르지 않도록 주의하세요.

---

# 22. 행사 전에 꼭 확인하세요

실제 행사 전에 다음 내용을 미리 확인하는 것을 추천합니다.

- 모든 효과음 버튼을 한 번씩 눌러보기
- 박수와 환호 음량 확인
- BGM 음량 확인
- 효과음 Fade 확인
- BGM Fade 확인
- ESC 전체 정지 확인
- DUCK이 자연스럽게 작동하는지 확인
- 운영 메모가 저장되는지 확인
- 브라우저를 껐다 켜도 음원이 남아 있는지 확인
- 컴퓨터 절전 모드가 켜져 있지 않은지 확인
- 카카오톡, Windows 알림 등의 소리가 행사 중 나오지 않도록 확인

# 23. 추천 사용 방법

시상식이라면 이런 식으로 사용할 수 있습니다.

### 행사 시작 전

오프닝 BGM을 재생합니다.

### 진행자가 행사 시작

BGM Fade를 눌러 음악을 자연스럽게 종료합니다.

### 수상자 발표 직전

🥁 두구두구 효과음을 재생합니다.

### 수상자 발표

✨ 짜잔 효과음을 재생합니다.

### 수상자가 앞으로 나올 때

👏 박수 또는 🎉 환호를 재생합니다.

박수가 너무 길면 효과음 Fade를 눌러 자연스럽게 종료합니다.

### 문제가 생겼을 때

ESC를 눌러 모든 소리를 즉시 정지합니다.

---

# 24. 가장 중요한 기능 5개

처음 사용하는 사람이라면 아래 5개만 기억해도 충분합니다.

**① 효과음 버튼을 누르면 바로 소리가 나온다.**

**② BGM은 따로 재생할 수 있다.**

**③ Fade를 누르면 소리가 천천히 작아진다.**

**④ ESC를 누르면 모든 소리가 즉시 멈춘다.**

**⑤ 설정과 메모는 자동으로 저장된다.**
